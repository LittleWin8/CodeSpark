品牌故事

从一座小山坡开始的咖啡实验

2014 年，我们在城市边缘的一间旧仓库里支起了第一台烘焙机。没有菜单， 只有一张手写的豆单和一把手冲壶。我们想做的事很简单——把那些容易被忽略 的风味，认真地呈现给愿意停下来的人。

今天，{{appName}}有了三间门店和一间烘焙工坊。规模变大了，但我们对味道的 偏执没有变：小批量烘焙、按需研磨、当日出品。

  • 只选用 84 分以上的精品级生豆
  • 每批次烘焙后 48 小时内完成风味杯测
  • 所有咖啡豆均可追溯至具体庄园与处理批次
我们的特色

四件我们从不妥协的事

单一产地
